# `@itsrose/react`

Core React UI components, layout primitives, and hooks tailored for the ItsRose platform.

## Features

- **Components**: Pre-built accessible components.
- **Hooks**: Utility hooks.
- **Core Primitives**: `createContext`, `forwardRef`, `cn`, and `tv` (via `tailwind-variants`).
- **Styling**: Tailwind CSS v4 component styles via `@itsrose/react/styles`.

## Setup Styles

Import the component stylesheet into your global CSS:

```css
@import "@itsrose/react/styles";
```
