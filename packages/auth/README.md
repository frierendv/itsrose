# `@itsrose/auth`

Authentication, billing, email, and storage integration for the ItsRose platform built on top of Better Auth.

## Installation

```bash
pnpm add @itsrose/auth
```

## Overview

This package provides server and client configurations for Better Auth, including subscription lifecycle handling, transactional email delivery via Eusend, and S3-compatible asset storage.

For implementation details, plugin configurations, and available exports, please refer directly to the [source code](./src).
