# Schema validation/types

Represent midtrans schema (Object)

## Variable Naming format

For **schema** it is always prefixed with `Schema` in the last.

Format: `[Camelcase_NAMESPACE][CamelCase_ObjectName]Schema`

Example: `SnapItemDetailsSchema`.

`Snap` is related to `snap` or folder name, `ItemDetails` is the object name and `Schema` is the prefix.

For Types same like schema without prefix refering to the schema, eg. `SnapItemDetails`.
